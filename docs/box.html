An always-on box

A laptop is where you try Dobby. A house needs a machine that is always on, running Home Assistant and Dobby together. This is the hardware we propose.

A proposal, not a walk Nobody has bought this box, installed both halves, and written down what happened. The parts and prices are from August 2026. When the walk is taken, this page and the installed-service section will be rewritten from it.

What each half needs

Home Assistant wants a machine of its own. Home Assistant OS manages its own updates, add-ons, and backups, and you cannot install other software into it. Give it a small box or a virtual machine.

Dobby is an ordinary Linux service: Erlang and Elixir, PostgreSQL, Avahi for the dobby.local name, and an outbound connection to a model provider. It needs a few hundred megabytes of memory and no GPU. The model is a call over HTTPS.

One box: a mini PC running Proxmox

This is the layout Dobby was designed for. A small x86 mini PC runs Proxmox VE, a free hypervisor. Each half gets a virtual machine.

PartProposedWhy
BoxIntel N100 or N150 mini PC, 16–32 GB RAM, 500 GB–1 TB NVMe. About $200–250.Near-silent, 6–10 W idle, a well-worn Proxmox host. 16 GB is enough; 32 GB is comfortable.
VM 1: Home AssistantHAOS from the official VM image. 2 vCPU, 4 GB.HAOS in its own VM, so add-ons and updates work as designed.
VM 2: DobbyDebian. 2 vCPU, 4 GB. Dobby under /opt/dobby, PostgreSQL, Avahi.A plain Linux host you can ssh into. Everything the household changes is two files under /opt/dobby/config.
RadiosA Zigbee or Z-Wave USB stick, passed through to the HA VM. Only if you have those devices.Home Assistant owns the radios. Dobby never talks to one.
PowerA small UPS.The house's brain should survive a blip. HA can watch the UPS over NUT.

Both VMs sit on the home LAN. Nothing is forwarded in from the internet. The only traffic that leaves is Dobby's call to the model provider. To reach the box from away, use a mesh VPN on the Dobby VM, not a port forward.

Two boxes: an appliance and a helper

If Home Assistant already runs on its own hardware (a Green, a Yellow, a Raspberry Pi), keep it. Dobby needs one more small machine on the same network.

  • Home Assistant Green is the appliance Home Assistant's own company sells: silent, about 1.7 W idle, 4 GB RAM, 32 GB storage, $199 as of January 2026. It runs HAOS and nothing else.
  • For Dobby, the same mini PC running Debian directly, or a Raspberry Pi 5 with 8 GB. Either runs Erlang well.

Two boxes cost a little more. In exchange, Home Assistant stays an appliance you never log into, and you can break Dobby's machine without touching the house's automations.

What you do not need

  • A GPU. Inference is a network call.
  • A public address or TLS. Dobby is LAN only.
  • Much storage. Dobby's state is one Postgres database and two files. That is the whole backup.

Then what

With the box up, follow the rest of the guide: describe the house, verify, set lan: true, and open dobby.local from the kitchen. The release steps (building it, the systemd unit, upgrades, restoring a backup) are still owed a walk.
