Growing the house

Four ways to add a device. They all end in the same file, and nothing enters the house until somebody says yes.

Four ways

  1. Say it. "What does Home Assistant have that we don't?" Dobby lists what it found and proposes an entry for the one you name. Say yes, and it is added.
  2. The cards. On /house: edit and remove on each card, add a device at the foot. The form asks only what the device type needs.
  3. The file. Edit home.yaml and restart Dobby.
  4. Your own agent. Anything the first way can do, an agent over MCP can do. See Your own agent.

Every way runs the same checks. An entry that would not boot from the file is refused at the form, in the thread, and over MCP, with the same sentence.

Proposed is not done

When Dobby or an agent adds a device, it happens in two steps. First a proposal: Dobby checks the entity exists, is not already in use, and the id is free, then gives the proposal a number. Nothing is written. Then a confirmation: somebody says yes to that number, and the entry goes into the file. The house restarts with the new device.

Dobby says "proposed" until the yes lands, and "added" only after. It does not blur the two.

What you should see

{"applied":false,"proposal":{"id":1,"device":"light:kitchen","name":"kitchen lights", "type":"light","status":"proposed","proposed_by":"Maya's walkthrough", "entry":{"id":"light:kitchen","type":"light","name":"kitchen lights", "aliases":["the kitchen light"],"bindings":{"light":"light.kitchen_lights"}}}}

A proposal as the tool returns it: applied: false, a number, and the exact entry it would write. In the thread, Dobby says the same in a sentence.

The whole house in one breath

You do not have to add devices one at a time. Tell Dobby what you have: "the thermostat, these four lights, the vacuum, the printer, all on Home Assistant." Dobby asks Home Assistant once, proposes every match as one numbered list, and one yes adopts the lot.

Anything you named that Home Assistant does not show, Dobby says it cannot see. It will not guess. And each entry stays "proposed" until its own confirmation applies. However many devices you confirm at once, the house restarts once.

The moment after

A new device reads NOT KNOWN for a moment. The house has a new device and has not heard from Home Assistant about it yet. The first sync fills it in.

What you should see

kitchen lightsNot known
kitchen lights71%Set

The same row a second or two apart.

Removing one

remove on a card asks once, in place: Remove kitchen lights? with remove and keep it. Then the entry leaves the file and the house restarts without it. There is no undo; add it back if you change your mind.
